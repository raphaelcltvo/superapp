# Códigos de erro

Lista completa dos códigos de Erro que a API pode retornar

<br />

| Código | Nome técnico                                          | Descrição                                                                                                        | Possível solução                                                                                      |
| :----- | :---------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------- |
| `900`  | `GENERIC`                                             | Erro interno, comunique o time técnico.                                                                          | Entrar em contato com o suporte.                                                                      |
| `901`  | `AUTHENTICATION`                                      | Token inválido ou expirado.                                                                                      | Gerar um novo token de acesso.                                                                        |
| `902`  | `INVALID_DATA`                                        | Erro na validação dos dados enviados.                                                                            | Verificar os dados enviados na requisição.                                                            |
| `904`  | `ORDER_ALREADY_EXISTS`                                | Pedido com o `order_id` informado já importado.                                                                  | Enviar o pedido com um novo `order_id`.                                                               |
| `906`  | `COD_STORE_NOT_FOUND`                                 | Loja não encontrada.                                                                                             | Verificar se o `cod_store` informado confere com o cadastrado na loja.                                |
| `907`  | `CARD_ALREADY_IN_USE`                                 | Esta comanda já está em uso.                                                                                     | Enviar a comanda com outro número.                                                                    |
| `908`  | `TABLE_NOT_FOUND`                                     | A loja não possui mesa com esse identificador.                                                                   | Criar a mesa com esse identificador ou informar outro número de mesa válido.                          |
| `910`  | `ORDER_CARD_NOT_FOUND`                                | A loja não possui comanda com esse identificador.                                                                | Criar a comanda com esse identificador ou informar outro número de comanda válido.                    |
| `912`  | `SALE_IN_CLOSING_STATUS`                              | Esta mesa/comanda está em fechamento e não aceitará mais itens.                                                  | Enviar o pedido para outra mesa/comanda e informar a referência nas observações, se necessário.       |
| `914`  | `SALE_WITHOU_ORDER_ID`                                | Não existe pedido com esse identificador.                                                                        | Verificar o ID enviado.                                                                               |
| `915`  | `UNMAPPED_915`                                        | O identificador informado já está sendo utilizado por um pedido.                                                 | Usar outro identificador para o pedido.                                                               |
| `916`  | `CARD_NOT_EXISTS`                                     | A comanda informada não existe no sistema.                                                                       | Usar uma comanda ativa ou criar a comanda no sistema Saipos.                                          |
| `917`  | `SAIPOS_AUTHORIZATION_REQUIRED`                       | A integração está com o token inválido.                                                                          | Regerar o token salvando o canal de venda em Menu > Canais de Venda > Escolha a Integração > Salvar.  |
| `918`  | `PARTNER_UPDATE_STATUS_WEBHOOK_RESPONSE_ERROR`        | Parceiro retornou erro no webhook de troca de status de pedido.                                                  | Verificar o status e a resposta do webhook do parceiro.                                               |
| `919`  | `INVALID_ORDER`                                       | Pedido inválido.                                                                                                 | Cadastrar novamente com outro `order_id`.                                                             |
| `920`  | `NO_CASHIER_OPEN`                                     | A loja está sem caixa aberto.                                                                                    | Erro com tratamento interno; o pedido será importado após o restaurante abrir um caixa.               |
| `921`  | `ALREADY_PROCESSING`                                  | O pedido já está sendo processado no momento.                                                                    | Aguardar e verificar se o pedido já foi processado.                                                   |
| `922`  | `VALUE_TOO_LONG`                                      | Valor informado em campo maior que o esperado.                                                                   | Verificar o corpo da requisição e os tamanhos dos campos enviados.                                    |
| `923`  | `BAD_ADDRESS`                                         | Estrutura de endereço inválida.                                                                                  | Verificar o endereço enviado.                                                                         |
| `924`  | `BAD_PHONE`                                           | É obrigatória a inserção do telefone do cliente.                                                                 | Verificar o campo de telefone do cliente.                                                             |
| `925`  | `SAIPOS_BAD_GATEWAY` / `SAIPOS_INTERNAL_SERVER_ERROR` | Ocorreu um problema em nossa infraestrutura; tente novamente mais tarde.                                         | Entrar em contato com o suporte, caso persista.                                                       |
| `926`  | `MORE_THAN_ONE_CASHIER`                               | Existe mais de um caixa aberto; selecione um caixa para importar o pedido.                                       | Erro com tratamento interno; o pedido será importado após o restaurante selecionar um caixa.          |
| `927`  | `CITY_NOT_FOUND`                                      | A cidade não foi encontrada.                                                                                     | Verificar a cidade enviada.                                                                           |
| `928`  | `DISTRICT_INSERT_EXCEED_TIME`                         | O bairro não foi encontrado. Selecione no sistema o bairro para importar o pedido.                               | Erro com tratamento interno; será resolvido após o restaurante selecionar o bairro no sistema Saipos. |
| `929`  | `STORE_DISTRICT_DIVIDED`                              | Bairro com subdivisões. Selecione no sistema o bairro para importar o pedido.                                    | Erro com tratamento interno; será resolvido após o restaurante selecionar o bairro no sistema Saipos. |
| `930`  | `PAYMENT_TYPE_NOT_FOUND`                              | Forma de pagamento não encontrada.                                                                               | Entrar em contato com o suporte para validar a forma de pagamento selecionada.                        |
| `931`  | `TABLE_BUSY`                                          | Mesa indisponível no momento.                                                                                    | Selecionar outra mesa ou, se aplicável, adicionar itens à comanda da mesa.                            |
| `932`  | `CANNOT_CREATE_TABLE_ORDER_WHEN_HAS_CARD`             | Não é possível criar pedidos de mesa sem comanda enquanto houver mais de uma comanda cadastrada/ativa na Saipos. | Desabilitar as comandas da loja no sistema Saipos, conforme regra de operação.                        |
| `934`  | `NO_FREE_CARDS`                                       | Sem comandas livres no momento.                                                                                  | Liberar mais comandas ou aguardar a liberação das comandas em uso.                                    |
| `935`  | `STORE_PARTNER_SALE_DISABLED`                         | Loja não está habilitada para vendas com parceiros.                                                              | Habilitar a integração no canal de vendas da Saipos.                                                  |
| `936`  | `PARTNER_NOT_AUTHORIZED`                              | Recurso não habilitado para o parceiro.                                                                          | Validar a liberação do endpoint para o parceiro.                                                      |
| `937`  | `ORDER_IS_STALE`                                      | O pedido é muito antigo e não pode ser importado.                                                                | Verificar a data/hora do pedido enviado.                                                              |
| `938`  | `ORDER_NOT_IMPORTED_BY_RESTAURANT`                    | Pedido não foi importado pelo restaurante.                                                                       | Garantir a importação do pedido pelo restaurante antes de novas alterações.                           |
| `950`  | `CONTINGENCY`                                         | Em contingência                                                                                                  | Sistema em modo de contingência, aguardar o retorno para realizar consultas (GET)                     |
