# Changelog

O objetivo deste changelog é fornecer visibilidade clara e transparente sobre a evolução contínua da API de Pedidos

# Mudanças recentes

## 02/07/2026

**\[Erros] Inclusão de erro 950 - contingency**

Foi adicionada a existência do erro 950  que indica que o sistema está em modo Contingência, portanto, não será possível utilizar os endpoints GET.

## 30/01/2026

#### **\[Campos] Inclusão do campo email**

Foi adicionada a existência do campo *email*, que permite receber o email do cliente e integrar diretamente ao nosso cadastro na Saipos.

#### **\[Campos] Inclusão do campo localizer**

Foi adicionada a existência do campo *localizer*, que permite receber o código de confirmação de entrega do pedido utilizado pelo entregador

#### **\[Campos] Inclusão do campo pickupCode**

Foi adicionada a existência do campo *localizer*, que permite receber de coleta do pedido na loja para que seja retirado pelo entregador
